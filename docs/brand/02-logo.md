# 02 Logo (PDF p.3 to 6)

## Name and wordmark
The name is always written in Latin letters as "Orrery" in every language, layout and channel. Pronounced OR-uh-ree. Working codename, not cleared; assets are generated by script and renamed by editing one string (`brand.json`).
- **Wordmark typeface.** Alexandria SemiBold (600), tracking -0.5%, outlined to paths. Never typed live in a font.
- **Case.** "Orrery" with a capital O. Never all caps, never all lowercase.
- **In Arabic text.** Keep the Latin name inside the Arabic sentence, isolated as left-to-right (e.g. `<bdi>` in HTML). Do not transliterate it into Arabic letters, in the logo or in copy. (Reviewers propose relaxing this for running text; see `10-open-items.md`. NOT applied.)
- **In running text.** Plain "Orrery", no TM or (R) until the mark is registered.
- **Outlined.** The lockup SVGs now carry outlines generated from the real Alexandria SemiBold (wght 600, instanced from the variable font), tracking -0.5% em, GPOS kerning applied (only pair found: r+y, +24/1000 em). No live text, no font reference. Outlined paths are artwork, not a font file.
- **Final form.** Once cleared, a designer reviews and may hand-tune the generated outline: spacing, the two r's, the tail of the y.

## Mark: Quadrant
An astronomer's quadrant split by its sighting arm. Measured, exact, moving forward; no calligraphy or pattern. Construction on a 32-unit grid:

| Element | Specification |
|---|---|
| Quarter disc | Corner at (5, 27), radius 22.5 units |
| Lower sector | 0 to 40 degrees from the horizontal edge |
| Sighting slot | 40 to 52 degrees, a 12 degree radial gap from the corner to the arc |
| Upper sector | 52 to 90 degrees |
| Flat bottom edge | The baseline; aligns with the wordmark baseline |
| Bounding box | x 5 to 27.5, y 4.5 to 27 |

- Always upright: flat edge at the bottom, corner at the bottom left. Never rotated, flipped or mirrored, including in RTL layouts.
- One colour by default. Two-tone is optional, marketing only.
- The slot must stay open at every size. Below 24 px use the hand-tuned small versions once they exist (not yet; see open items).

## Lockup, clear space, minimum sizes
One lockup in v1: mark to the left of the wordmark, wordmark baseline on the quadrant's flat edge. X = cap height of the wordmark (measured: OS/2 sCapHeight = 700/1000 em, so X = 0.70 em).

| Rule | Value |
|---|---|
| Mark height (visible) | 1.4 X |
| Gap mark to wordmark | 0.6 X |
| Baseline | Wordmark baseline = quadrant's flat bottom edge |
| Clear space | 1 X on every side of the lockup |
| Minimum lockup width | 80 px on screen, 20 mm in print |
| Minimum mark alone | 16 px on screen, 5 mm in print |

- **RTL layouts.** The lockup never mirrors: the mark stays left of "Orrery". Place the whole lockup at the start of the layout (right-hand side in Arabic).
- **Mark alone.** Where the name is already present or space is tight: app icon, favicon, chat avatar, social profile.
- **Stacked lockup.** Not part of v1. Add only if a real application needs it, drawn by a designer to the same baseline rule.

## Do not
- Rotate, flip or mirror the mark, or the lockup in RTL layouts.
- Close, widen or narrow the sighting slot.
- Set the wordmark in Coral, or in any typeface other than the outlined Alexandria SemiBold.
- Add gradients, glows, shadows, outlines or 3D effects.
- Put the mark inside a circle or any container other than the app icon tile.
- Transliterate the name into Arabic letters or add an Arabic wordmark.
- Place the logo on busy photos or on colours that fail the contrast table.

## Generated SVG notes

Wordmark: with `ORRERY_FONT_ALEXANDRIA=/path/to/Alexandria-VF.ttf` set, `tools/build_logo.py` and `tools/build_logo_proposed.py` (shared helper `tools/wordmark_outline.py`, needs fontTools) outline the name at wght 600. The ink left edge sits 0.6 X from the quadrant, the baseline on the quadrant's flat edge, clear space 1 X on the right. Font source: https://github.com/Gue3bara/Alexandria (SIL OFL 1.1), file not in the repo.
