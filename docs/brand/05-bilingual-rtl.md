# 05 Bilingual and right-to-left rules (PDF p.10)

Arabic and English are equal: neither is a smaller translation under the other. The product follows the owner's chosen language; marketing ships a complete version in each.

| Element | In right-to-left layouts |
|---|---|
| Page layout, navigation, alignment | Mirror |
| Progress, steps, sliders, carousels | Mirror (they run right to left) |
| Directional icons (back, next, send, undo) | Mirror |
| Logo, mark and lockup | Never mirror |
| Numbers, amounts, dates | Keep left-to-right inside the line |
| Chart axes | Keep left-to-right; mirror only legends and surrounding layout |
| The name "Orrery" in Arabic text | Keep Latin, isolate as left-to-right |

- **Writing.** Arabic is written natively in clear Modern Standard Arabic with a Gulf-friendly tone, never translated word for word. Every Arabic headline and tagline gets a native-speaker review before release.
- **Bilingual documents.** Where both languages share a page, equal size and weight: Arabic on the right, English on the left.
- **Tax invoices.** ZATCA requires Arabic on Saudi tax invoices; other languages may sit alongside it. Confirm the final template with a compliance advisor.
