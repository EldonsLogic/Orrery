# 06 Voice and tone (PDF p.11)

Orrery speaks like a capable operations lead: direct, confident, exact. It leads with the result, uses numbers instead of adjectives, and always says what happens next.
- **Direct.** Lead with the outcome. One message, one action.
- **Confident.** No hedging filler and no hype. When unsure, say exactly what is missing.
- **Exact.** Numbers, dates, names and amounts. Never "some", "soon" or "a few".

| Situation | Write | Not |
|---|---|---|
| Task done | Done. Inventory is live and linked to sales. Run the one-month simulation now? | Great news! We've successfully set up your amazing new inventory module! |
| Missing data | I can't close March yet: 4 supplier receipts are missing. Upload them or mark them as pending. | Oops, something went wrong with your data. |
| Error | Invoice INV-0418 was rejected: the buyer's VAT number has 14 digits, not 15. Fix it and resend. | We're sorry, an error occurred. Please try again later. |
| Arabic, task done | تمّ. المخزون يعمل الآن ومربوط بالمبيعات. هل نشغّل محاكاة الشهر الآن؟ | تم بنجاح إعداد وحدة المخزون الرائعة الخاصة بك! |

- **Arabic.** Modern Standard Arabic, Gulf-friendly, addressing the owner directly as أنت. Avoid stiff passive constructions and heavy dialect.
- **Words to avoid.** AI-powered, magic, seamless, revolutionary, leverage, enterprise-grade. Talk about the business, not the technology.
- **Words to use.** Your business (not organisation), set up (not implement), simulation / محاكاة, ZATCA in English and هيئة الزكاة والضريبة والجمارك on first mention in Arabic.
