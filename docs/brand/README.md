# Brand and design system: Seshna

**Status.** The product name **Seshna** (seshna.com), the **Nuqta S** mark, the **Cairo Bold** outlined wordmark and **Cairo for headings with Readex Pro for body** are final founder decisions of 2026-11-23 (ADR-0066). The palette, type scale and components of Brand guidelines v1 (6 November 2026) are unchanged. Still open: the trademark search on the name and mark in Saudi Arabia, the UAE, Egypt and Qatar (see `10-open-items.md`).

Logo source: the Seshna logo kit "Nuqta S", draft v3, regenerated in this repo by `tools/build_logo.py` (provenance in `tools/PROVENANCE.md`).

## Regenerate the logo set
1. Marks and app icons (stdlib): `python3 tools/build_logo.py`.
2. Wordmark and lockups need the Cairo variable font outside the repo (pinned source in `tools/PROVENANCE.md`): `SESHNA_FONT_CAIRO=/path/to/Cairo-VF.ttf uv run --no-project --with fonttools --with uharfbuzz python3 tools/build_logo.py`. Without the variable the wordmark and lockups are left as they are.
3. Rasters (stdlib, deterministic, byte for byte): `uv run --no-project --python 3.12 python3 tools/build_icons.py`; `--check` fails when a committed PNG or ICO differs.
4. Size set: `python3 scripts/build_brand_assets.py` (from the repo root; `--check` in CI).
5. The web app copies `logo/app-icon.svg`, `logo/mark-small.svg` and the `logo/png/` web icons at build time (`web/scripts/copy-tokens.mjs`).

Rule that survives any change: the name is always written in Latin letters and never in Arabic script (`latinNameAlways`, `arabicScriptNever`).

## For any AI model
1. Read `tokens/tokens.json` first, then the relevant section doc.
2. Use the CSS variables from `tokens/tokens.css`; never hardcode hex values.
3. Do not invent brand rules. Where a doc says INFERRED, PROPOSED or DRAFT, it is not an approved rule.
4. After editing tokens.json run `python3 tools/build_tokens_css.py` and `python3 tools/check_contrast.py`.
