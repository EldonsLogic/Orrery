## Rename the product
1. Edit `name` in `brand.json`.
2. Run `ORRERY_FONT_ALEXANDRIA=/path/to/Alexandria-VF.ttf python3 tools/build_logo.py` (regenerates `logo/`; without the variable lockups fall back to PLACEHOLDER live text).
3. Search the docs for the old name. Prose files still say "Orrery" and `preview.html` hardcodes it (INFERRED limitation: only the SVGs are generated).
Rule that survives a rename: the name is always written in Latin letters (`latinNameAlways`).

## For any AI model
1. Read `tokens/tokens.json` first, then the relevant section doc.
2. Use the CSS variables from `tokens/tokens.css`; never hardcode hex values.
3. Do not invent brand rules. Where a doc says INFERRED or PROPOSED, it is not an approved rule.
4. After editing tokens.json run `python3 tools/build_tokens_css.py` and `python3 tools/check_contrast.py`.
