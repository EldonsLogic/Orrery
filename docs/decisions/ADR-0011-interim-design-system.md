# ADR-0011: Interim design system is brand guidelines v1 (Quadrant); logo is a placeholder

Status: Accepted
Owner: eldon
Approved by: Eldon; partner review pending (GOV-013)

## Context
UI work needs tokens now, but the name is not cleared (ADR-0001). Brand guidelines v1 and tokens exist in [../brand/README.md](../brand/README.md).

## Decision
Use brand guidelines v1 (Quadrant) and its tokens as the interim design system for all UI. The logo and wordmark are placeholders until the name is cleared and the identity is agreed. A full rollout (all logo files, sizes, favicons, social sizes, product design system, final guidelines) happens after name clearance (BRD-009).

## Alternatives rejected
- Wait for the final identity: blocks UI work.
- Design ad hoc per screen: inconsistent, breaks theming.

## Consequences
- Colours come only from tokens (see ADR-0014).
- Font and icon licences must be verified (BRD-011, BRD-012).
- Expect a rebrand pass later.

## Supersedes
none
