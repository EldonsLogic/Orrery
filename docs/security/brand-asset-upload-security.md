# Brand asset upload security

Status: draft
Owner: eldon

Applies to tenant logos, favicons and any branding upload ([../product/theming-and-tenant-branding.md](../product/theming-and-tenant-branding.md)). Uploaded files are untrusted.

| Control | Rule |
|---|---|
| Who can upload | Owner and admin roles only; authenticated, CSRF-protected, rate limited |
| Allowed types | PNG, JPG, SVG only. Decided by content sniffing (magic bytes), not by extension or client MIME type |
| Size limits | Initial values to set at build: max file size (e.g. a few MB), max pixel dimensions, minimum logo resolution; reject decompression bombs (check dimensions before decode) |
| Images (PNG/JPG) | Re-encode server-side (strip EXIF/metadata, ICC oddities, appended data); output new file |
| SVG | Parse with a safe parser then sanitise with an allow-list: strip `script`, event handlers (`on*`), `foreignObject`, `style` with external URLs, `use` and `image` with external `href`, `a` links, entities/DTDs (XXE), `data:` and `javascript:` URLs; limit nodes and depth; prefer rasterising to PNG for places where vector is not required; reject if nothing safe remains |
| Malware scan | Scan every upload before storage use; quarantine on detect; scanner service and region on the processor list |
| Storage | Per-tenant prefix/bucket, private by default, encrypted, no executable permissions; original kept only in quarantine until scanned, derived assets stored; deletion with tenant deletion |
| Serving | From a separate cookie-less asset origin/domain; `Content-Type` set by us; `X-Content-Type-Options: nosniff`; `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'` (or sandbox) for SVG responses; `Content-Disposition` as needed; long cache with content-hash URLs; no directory listing |
| Embedding | Render logos via `<img>`, never inline SVG from tenant input |
| Documents (PDF/email) | Logos embedded as sanitised raster or sanitised SVG converted at generation; compliance layout is fixed |
| Derived assets | Favicons and dark/light variants generated by the platform from the sanitised source |
| Logging | Upload events (who, hash, result, scan verdict) in the audit log |
| Terms | Brand asset licence and user content terms in [../legal/checklist.md](../legal/checklist.md): tenant warrants rights to the logo |
| Tests | Malicious sample corpus in CI (script SVGs, XXE, polyglots, oversized images, renamed executables) |
